### Chess
This version of chess is written to play PvP, both players on the same computer
Sounds aren't implemented, but the code has some placeholders for them so it's easy to add them
Code was written in Polish language, using C++ and raylib library
For bishop, rook and queen I have implemented my own algorithm that scans chessboards for possible checks or pinns
